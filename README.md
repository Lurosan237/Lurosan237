I study **mathematics** and taught myself to code, starting on Khan Academy. Maths is the thread through all my work: probability, proof and modelling.
I like hard problems, and I'm happy to work anywhere in the stack. I've written **a consensus algorithm from scratch**, **an exactly‑once
streaming pipeline**, **fraud models**, **an AI maths tutor**, **mobile apps** and **3D match replays**. I learn whatever the problem
needs, then I finish it: tested, measured, and live where anyone can try it.

### 🧭 How I work

- **Self‑taught: I learn what the problem needs.** Raft, Flink, PDF font internals, zero‑knowledge proofs: I learned each one from docs and papers because a project needed it.
- **Think like a mathematician.** State exactly what should be true, then check it. Every README has a baseline, an unseen test set and a link to the report.
- **Anyone can try it.** Live demos run in the browser, with nothing to install.
